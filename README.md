# MERN Stack Project Group 14
Ducky Dollars is a budget tracking application that uses the MERN stack.
Users can set their monthly budgets by creating categories and adding transactions to those categories.
The app states when the user is within or over budget and utilizes graphs to help see changes in their budget.
